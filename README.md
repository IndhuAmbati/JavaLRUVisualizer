# Java LRU Cache Visualizer

This is a standalone mini-project that includes:

- `LRUCache.java` for the Java implementation
- `index.html`, `script.js`, and `style.css` for the browser visualizer
- `DELETE` support in both the Java cache and the visual UI

## Run the Java demo

```powershell
cd JavaLRUVisualizer
javac LRUCache.java
java LRUCache
```

## Run the visualizer

Open `index.html` in your browser.

## Features

- Initialize cache capacity
- `PUT` key/value pairs
- `GET` values
- `DELETE` existing keys
- View cache order from most recent to least recent
