How LRU Cache Works

  • GET: Retrieves the value and moves that item to the front.
  • PUT: Adds or updates an item and evicts the least recent item when full.
  • DELETE: Removes a key from the cache if it exists.
  • Capacity: Maximum number of items the cache can hold.
