Concept

How LRU behaves

GET

Reads a value and moves that entry to the most recent position.

PUT

Adds or updates an entry and may evict the oldest one if capacity is full.

DELETE

Removes an entry from the cache and updates the current ordering.

Capacity

Defines the maximum number of entries the cache can keep at one time.
